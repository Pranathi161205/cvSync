# CVSync – AI-Powered Resume Analyzer

Live Demo: https://cvsycn.netlify.app/

---

## Overview

CVSync is an AI-powered resume analysis platform designed to evaluate resumes against job descriptions and provide ATS-based insights. The application helps users improve their resumes by identifying matched skills, missing keywords, ATS score, and personalized improvement suggestions.

The platform streamlines the recruitment preparation process using AI-driven analysis and modern web technologies.

---

## Features

- AI-powered resume analysis
- ATS score generation
- Resume and job description matching
- Skill extraction and keyword analysis
- Missing skill identification
- Resume improvement suggestions
- PDF resume upload support
- FastAPI backend integration
- Responsive frontend interface
- MongoDB database integration
